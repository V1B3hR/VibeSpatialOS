# VibeSpatialOS

Glasses-free Spatial Operating System for CAD/BIM & Digital Twins with 40kHz Mid-Air Ultrasonic Haptics, 9-DoF IMU/EMG Wearable Telemetry, and 6-DoF SVD Closed-Loop Tracking.

## Features

- **Mid-Air Ultrasonic Haptics** — 40 kHz phased-array transducer grid for tactile feedback without physical contact
- **Wearable Telemetry** — 9-DoF IMU + EMG sensor fusion for hand/gesture intent capture
- **6-DoF Closed-Loop Tracking** — SVD-based pose estimation for sub-millimetre spatial accuracy
- **CAD/BIM Integration** — Native support for IFC, STEP, and common digital-twin formats
- **Glasses-Free Display** — No head-mounted display required; works with standard depth-sensing setups
